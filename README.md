# Kit del Reto de 4 días · eCom Society

Las skills que usamos en el reto para que Claude Code haga cada tarea contigo.

## Cómo instalarlo

Abre Claude Code en tu carpeta del reto y pega estos dos mensajes, uno a la vez:

```
/plugin marketplace add ecommaster777/reto-ecom-society
```

```
/plugin install reto@ecom-society
```

Después cierra Claude con `/exit` y vuelve a abrirlo con `claude`.

## Las skills

| Skill | Cuándo | Cómo se usa |
|---|---|---|
| Herramientas | Antes de cada clase | `/reto:herramientas` |
| Producto | Miércoles y jueves | `/reto:producto` |

Las skills de tienda, anuncios y números llegan durante la semana. Para tenerlas, escribe `/plugin update reto@ecom-society`.
